# الأغنية

ارفع هنا ملف أغنية أم كلثوم "ألف ليلة وليلة" (مقطع: الليل وسماه ونجومه وقمره) باسم:

```
song.mp3
```

لو الملف مش موجود، الدعوة هتشغل المقطوعة الرومانسية المدمجة (مقام نهاوند) تلقائياً.

لو رفعت الأغنية كاملة (حوالي ساعة)، حدد بداية ونهاية المقطع بالثواني في `assets/js/config.js`:
`musicStart` و `musicEnd`. الأسهل إنك ترفع المقطع لوحده.
